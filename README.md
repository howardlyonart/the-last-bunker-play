# The Last Bunker — Play Site

Public landing page for **The Last Bunker**.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Wait for GitHub Pages to deploy. The expected URL is https://howardlyonart.github.io/the-last-bunker-play/.

The landing page embeds the existing playable game at https://last-bunker.howardlyon.chatgpt.site/ and also offers a direct launch link. If the game host disallows iframe embedding, the direct link remains usable.

## Future updates

Update `index.html` to revise the page. To serve the game itself from GitHub Pages, copy the approved public build assets into this repository and point the iframe or Play button to that local build. Keep private development files and history in the private source repository.
